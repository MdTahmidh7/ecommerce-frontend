About Our E-Commerce App

This is a demo e-commerce frontend application built with Angular 18 and styled using Bootstrap 5.

It serves as the user interface for a Spring Boot backend, providing authentication (Login/Register) and a foundation for future e-commerce functionalities like product listings, cart management, and order processing.

Our Mission

To provide a seamless, secure, and enjoyable online shopping experience for users, backed by a robust and modular backend system.
